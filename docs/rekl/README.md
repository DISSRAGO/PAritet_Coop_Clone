# Сервис #РЕКЛ V0.51 — документация

Пакет канонической документации сервиса рекламаций, модерации и восстановления доверия HomoNet.

## Статус

- **Версия**: V0.51
- **Статус**: Canonical (утверждён)
- **Дата**: 2026-06-11
- **Подсистема**: сИНФ / сОРГ / сССЭ

## Ключевая идея

Сервис #РЕКЛ заменяет классическую «модераторскую панель» на институциональный механизм разрешения конфликтов. Модерация — частный случай рассмотрения рекламаций.

- **Пользователь → Жалоба → Модератор → Решение** — это НЕ HomoNet.
- **Субъект → Рекламация → Ответственный контур → Решение → Эскалация → Восстановление доверия** — это HomoNet.

UI-путь `/moderation` сохраняется как **фасад** сервиса #РЕКЛ.

- **Backend**: `backend/modules/reclamation/` (переименование модуля концептуально)

- **UI**: `/moderation` — фасад
- **DB**: схема `homonet`, таблицы `reclamation*` (12 штук)

## Связанные сервисы

- **#КОГИ** — рекламации на тханки, когОбъекты, комментарии, репосты
- **#ДЕЛО** — рекламации по процессам и обязательствам
- **#СЧЕТ** — рекламации по расчетам
- **#ДЕПО** — поручительство и обеспечение обязательств
- **#СТРХ** — компенсация ущерба
- **#ГЛАС / #ВЕЧЕ** — коллективное принятие решений
- **#СТАТ** — учет репутации

## Каноническая формула

```
Несогласие → Рекламация → Обсуждение → Решение → Исправление → Восстановление доверия → Развитие среды
```
